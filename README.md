# Tormin

A tiny BitTorrent client

- Torrent files and magnet links (drag & drop, paste, or open from the browser)
- Pick which files to download
- Per-torrent speed limit
- Lives in the tray, notifies when downloads finish
- Dark and light themes, compact mode
